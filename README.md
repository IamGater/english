# English — английский с A1 до B2

Интерактивный тренажёр на чистом HTML, CSS и JavaScript. Сборка и сервер не нужны: откройте `index.html` в браузере.

## Разделы

- **Обзор** — готовность к уровням A1, A2, B1, B2 с точным остатком («осталось выучить N слов, пройти M тем…»).
- **Словарь** — 3855 слов (A1 — 690, A2 — 663, B1 — 1085, B2 — 1417) с переводом, примерами и озвучкой; тренировка с интервальными повторениями и свободные карточки.
- **Грамматика** — 47 тем (A1 — 13, A2 — 11, B1 — 12, B2 — 11): правило и упражнения.
- **Практика** — на каждом уровне тест, диктант, три записи для аудирования, три текста для чтения и три диалога. Записи читает голос браузера, поэтому аудиофайлы не нужны.
- **Пробный экзамен** — в формате Cambridge English: чтение, аудирование, лексика и грамматика на время, проходной балл 60%. Письмо и говорение не входят. На готовность к уровню не влияет.
- **Работа над ошибками** — слова и упражнения, в которых были ошибки; верный ответ убирает вопрос из списка.
- **Статистика** — ответы по дням за 30 дней, слова по уровням, прогноз повторений на неделю, самые трудные слова.
- **Входной тест** — при первом посещении можно начать с нуля или определить уровень тестом (его же можно пройти позже из настроек).

## Как считается прогресс

Готовность к уровню = 50% слова + 30% грамматика + 20% практика; уровни накопительные.
Слово считается выученным после трёх верных ответов в три разных дня (в день знакомства, через 1 день и ещё через 3 дня); до этого оно даёт 25% и 60% вклада. Ошибка возвращает слово на первый этап. Тема, тест или диалог засчитываются от 80%.
Все эти числа — константы в начале `js/learning.js`.

Входной тест идёт по уровням от A1 к B2: 16 вопросов на уровень (8 слов и 8 упражнений из разных тем), зачёт от 80%, после первого незачтённого уровня тест заканчивается. Слова зачтённых уровней считаются выученными предварительно: каждое приходит на контрольное повторение в течение 60 дней и при ошибке возвращается в изучение.

## Устройство

Вся разметка лежит в `index.html`: экраны (`<section class="screen">`), окно настроек и шаблоны (`<template>`). JavaScript только показывает нужный экран и подставляет данные.

```
index.html
css/style.css
js/
  data/            данные по уровням
    words-a1.js … words-b2.js       слова: «слово|перевод|пример», строки с # — темы
    grammar-a1.js … grammar-b2.js   правила и упражнения
    dialogs-a1.js … dialogs-b2.js   диалоги
    listening-a1.js … listening-b2.js   тексты для аудирования и вопросы к ним
    reading-a1.js … reading-b2.js   тексты для чтения и вопросы к ним
  helpers.js       мелкие общие функции
  content.js       собирает данные всех уровней в общие списки
  storage.js       прогресс пользователя и localStorage
  learning.js      этапы слов, повторения, расчёт готовности к уровню
  speech.js        озвучка
  quiz.js          вопросы и ход викторины
  pages/           экраны: home, vocabulary, grammar, practice, listening (аудирование и диктант), reading, exam (пробный экзамен),
                   mistakes (работа над ошибками), stats (статистика), placement (приветствие и входной тест)
  settings.js      окно настроек
  main.js          навигация по адресу после #
```

Прогресс хранится в `localStorage` под ключом `english.progress`. В настройках (кнопка в шапке) есть тема, экспорт, импорт и сброс.
